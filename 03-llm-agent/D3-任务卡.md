# D3 任务卡：LLM / Agent —— 极简文档问答（Mini RAG）

> 时间盒 90 分钟。目标不是学会 LLM，是采集"设计 AI 流程"的体感数据。
> 卡壳超过 20 分钟 → 记一句卡在哪，然后跳过。卡壳密度本身就是数据。

**今天同时是一个对照实验**：你每天都在用 Agent 产品（包括我）。今天你要亲手搭一个最小版，
然后回答一个问题——**"用别人做好的 Agent"和"自己搭一个 Agent"，差别到底在哪？**
这个对比本身就是信息。

## 这个方向是什么（30 秒版，详细版见 PLAN.md 第 3 节）

- **做什么**：调 API、设计 prompt、搭 RAG、规划工具调用、调试对话逻辑、做自动化工作流
- **日常写什么代码**：大部分不是算法，是"工程"——怎么把文档切段、怎么检索、怎么拼 prompt、怎么评估回答质量、怎么控制成本
- **适合什么人**：享受"设计 AI 的思考过程"胜过"写算法本身"；对不稳定的输出有耐心
- **难点**：prompt 效果不稳定带来的挫败；方向迭代极快，要持续学
- **客观说优缺点**：需求大、新人有机会；但护城河在"把 AI 和业务流程焊死"的工程能力，不在 prompt 本身

## 第 2 步：读源码，建立三个根概念（20 分钟）

打开 `rag_demo.py`，只找三个函数，对应 RAG 的三步：

- **`load_chunks()` —— 切分**：为什么按 `##` 标题切，而不是每 500 字硬切？
  （提示：一个标题下的内容通常讲同一件事。真实项目里切分策略是门学问：切多大、重叠多少，直接影响检索质量）
- **`retrieve()` + `bigrams()` + `cosine()` —— 检索**：
  - 中文没有空格，怎么"算两段文字像不像"？答案是字符二元组：`大语言模型` → `大语/语言/言模/模型` 四个两字组，零依赖实现中文匹配
  - 余弦相似度只干一件事：比较两个"词频向量"的方向，0~1 之间，越大越像
  - **真实世界的 RAG 在这里换成"向量 embedding + 向量数据库"，但骨架一模一样**——都是一个"把问题和高相关段落匹配上"的检索器。今天你写的是它的极简祖先
- **`build_prompt()` —— 生成**：数数这个模板有几要素？角色/任务、资料、问题。
  你把一句"请只根据资料回答"删掉，模型的回答就可能开始自由发挥——**prompt 不是咒语，是把话说清楚**

## 第 3 步：动手改（30 分钟，至少完成 3 个）

> 改动循环：改 `rag_demo.py` → Ctrl+S → 终端 Ctrl+C 重跑 → 问同一个问题对比变化。

- [ ] 搜 `TOP_K = 2` 改成 `4`，问同一个问题：prompt 长了多少？材料变多一定更好吗？
- [ ] 用 `##` 格式往 `material.md` 加一节你自己的内容（比如你这周干的一件小事），
      然后问它关于你这段内容的问题——体验"喂自己的文档给 AI"（这就是企业知识库的最小形态）
- [ ] 搜 `build_prompt` 里的"请只根据下面给出的资料回答问题"，改成你自己的要求
      （比如"用大白话回答，100 字以内，先给结论"），看 prompt 怎么变
- [ ] 问一个资料里没有的问题，看它检索出什么——如果你的问题是"我们学校哪年建的"，
      它照样会拼出一段"资料"递给模型。**这时"不要使用资料之外的知识"这句话就是唯一的刹车**

## 第 4 步：拓展（15 分钟，选 1-2 个）

- [ ] **手动对照实验（没 API key 也能做，强烈推荐）**：
  把拼好的 prompt 复制到 DeepSeek / 通义 / Kimi 任一网页版，拿到回答 A；
  然后**不带资料**直接问同样的问题，拿到回答 B。
  对比 A 和 B：哪个更靠谱？哪个更像"你的文档在说话"？——**你刚刚完整走了一遍 RAG 的价值链**
- [ ] **接真 API（有 key 才做）**：任选一个国产 OpenAI 兼容 API（DeepSeek 最便宜，新用户有送额度）。
      在 `03-llm-agent` 下建 venv 装包：
      ```
      python -m venv venv
      venv/Scripts/pip install openai
      ```
      然后设三个环境变量再跑（PowerShell 语法，Git Bash 用 export）：
      ```
      $env:LLM_API_KEY="sk-你的key"
      $env:LLM_BASE_URL="https://api.deepseek.com"
      $env:LLM_MODEL="deepseek-chat"
      venv/Scripts/python rag_demo.py
      ```
      看到终端直接打印模型的回答，就是"真 RAG"跑通了
- [ ] 进阶（可选）：`bigrams()` 改成三元组（三字一组），检索变准还是变钝？
      或者给标题加权——标题命中的段落加分。卡住超 20 分钟就跳过，记进卡壳记录
