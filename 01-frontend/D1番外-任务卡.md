# D1 番外 · 待办升级版任务卡（分类徽标 + 完成度进度条）

> **为什么选这个**：两个新功能都贴着你的甜蜜区——视觉占比高、JS 密度低，
> 而且只验证一个你已经见过的概念：**界面是数据的函数**。
> 预计 60-90 分钟。规则同 D1：卡壳超 20 分钟就记下来跳过，卡壳密度就是数据。

## 这次升级了什么（对照 D1 旧版）

| 层 | 新东西 |
|----|--------|
| 数据层 | 每条待办多一个 `cat` 字段；新增一张 `CAT_STYLE` 表（分类 → 徽标配色） |
| 渲染层 | 每条多画一个分类徽标；顶部多一条完成度进度条（**算**出来的，不是画出来的） |
| 交互层 | 添加待办时多一个分类下拉框（选项由 `CATS` 数组自动生成） |
| 原样保留 | 双击编辑、过滤、清除已完成、localStorage 保存——D1 的代码一行没动 |

## 第 1 步：跑起来 + 看数据（10 分钟）

1. 预览/双击打开（首次打开有 3 条示例数据，进度条和徽标直接可见）
2. 加三条不同分类的待办 → 勾掉一条 → 看进度条和文字一起动
3. F12 → Console 输入 `todos` 回车：看每条多出来的 `cat` 字段
4. 如果你 D1 的旧待办还在：它们被自动补了默认分类「生活」（代码里搜 `补默认分类` 能看到那一行——旧系统升级时这是常态）

## 第 2 步：读源码，只抓三个点（20 分钟）

1. **`render()` 心智模型没变**——数据变了，重画。今天没有任何新魔法，不信就搜 `render()` 看它和 D1 是不是一个形状
2. **进度条是算出来的**：搜 `pct`，看 `doneCount / total * 100` 怎么变成一个 width 值。
   记住这个句式：**界面是数据的函数**——以后所有前端活儿都是这句话
3. **徽标颜色也来自数据**：搜 `badgeHtml`，看它怎么按分类查 `CAT_STYLE` 表。
   对照 D1 的 `--accent` 一课：集中管理 = 改一处，所有同类元素一起变

## 第 3 步：动手改（30 分钟，至少完成 2 个）

- [ ] 改 `CAT_STYLE` 里三个分类的配色（搜 `CAT_STYLE`）——比如「工作」换橙色系
- [ ] 改分类名：「工作」→「打工」、「学习」→「搞钱」（搜 `CATS`，只改这一处，下拉和徽标自动跟上）
- [ ] 加第四个分类：`CATS` 加一行 + `CAT_STYLE` 加一行，完事
- [ ] 进度条改色/改高度/改圆角（搜 `.progress-fill`）
- [ ] 用 F12 临时试样式，满意了再抄回文件（D1 的实验室工作法）

## 第 4 步：加功能（30 分钟，选 1 个）

- [ ] **分类筛选**：过滤行加「工作/学习/生活」按钮
  提示：`currentFilter` 现在只按 done 过滤，照它样子多加一个 `catFilter` 条件
- [ ] **分类小计**：每个分类显示「2/5」
  提示：进度条那段 `todos.filter(...)` 就是模板，换个条件复制三遍
- [ ] **进度文字加百分比**：「已完成 1 / 3 · 33%」（搜 `progress-text`，`pct` 已经算好了）
- [ ] **空状态文案**改成你的风格（搜 `empty-tip`）
