# D1 任务卡：前端开发 —— Todo 待办网页

> 时间盒 90 分钟。目标不是学会前端，是采集"视觉成就感 vs 反复调样式"的体感数据。
> 卡壳超过 20 分钟 → 在 `01-frontend/卡壳记录.md` 记一句卡在哪，然后跳过。卡壳密度本身就是数据。

## 第 1 步：跑起来（10 分钟）

1. 双击打开 `01-frontend/index.html`（或右键 → 用浏览器打开）
2. 随便玩：加 3 条待办 → 勾选完成 → 切换"未完成/已完成" → 刷新页面（数据还在，这是 localStorage 的魔法）
3. 按 F12 打开开发者工具，点 Elements 面板，直接双击页面上的文字改着玩——不用改源码、不用刷新，界面实时变。**这是前端的"显微镜"，今天就要摸熟。**

## 第 2 步：读源码，建立三个概念（20 分钟）

- HTML = 骨架（页面上有什么），CSS = 皮肤（长什么样），JS = 肌肉（怎么动）
- 重点读 `app.js` 里的 `render()`：前端最核心的心智模型——**数据变了，重画界面**。你只负责改数据，画面交给 render
- 顺手在 F12 的 Console 面板输入 `todos` 回车，直接看到内存里的待办数组

## 第 3 步：动手改（30 分钟，至少完成 3 个）

- [ ] 把 `style.css` 里的 `--accent` 改成你喜欢的颜色（改一行，全局变色）
- [ ] 改标题、副标题，改成你的风格
- [ ] 输入框 placeholder 改成你的口头禅
- [ ] 给已完成项换一种样式（变淡 / 加背景色 / 左边加竖线，随你）
- [ ] 用 F12 临时改样式，找到满意的效果后再抄进 `style.css`

## 第 4 步：加功能（30 分钟，选 1-2 个）

- [ ] 编辑功能：双击某条待办能改文字（提示：把 `<span>` 换成 `<input>`，或者加一个"✏️"按钮）
- [ ] 统计栏升级："今天已完成 X / Y"
- [ ] 空状态：没有待办时显示"🎉 全部搞定"（提示：`todos.length === 0` 时渲染一段提示）
- [ ] 进阶（可选）：拖动排序。卡住超过 20 分钟就跳过，记进卡壳记录

## 收尾（15 分钟）

1. 填 `templates/复盘卡片.md`（复制一份到 `01-frontend/` 再填）
2. git 提交今天的修改：
   ```
   git add 01-frontend/ && git commit -m "D1: 前端 Todo —— 我的修改"
   ```
3. 回来找我复盘，先回答一个问题：**"写一行代码，画面立刻变化"——这是享受还是无感？**

## 复盘要点（做完再回头看）

- 改样式时，烦的是"工具不听话"还是"这个活儿本身没意思"？前者是任务挫败，后者是方向信号
- 对比 D0 的三种掌控感（规则生效 / git 轨迹 / 追查 pip.ini 真相）：F12 实时改页面，是同一种爽感吗？
