# D1 名词表 —— 前端名词逐个讲透

> 看代码遇到不认识的词，回来查这里。每个名词按「一句话 → 类比 → 今天在哪用到 → 深入一点」四段写。
> 配套源码：`index.html`（待办清单）、`card/名片页.html`。

---

## HTML（超文本标记语言）

- **一句话**：用一对对标签描述页面结构的语言，是网页的“骨架”。
- **类比**：填空题的卷面——标题是哪空、正文是哪空、按钮是哪空，都规定好了。
- **今天在哪用到**：`index.html` 里 `<h1>`、`<input>`、`<button>`、`<ul>` 这些成对出现的尖括号标签。
- **深入一点**：标签分容器（div/main/section）、内容（h1/p/span）、控件（input/button/select）三类。浏览器按标签把 HTML 变成一棵“DOM 树”，JS 操作的正是这棵树。

## CSS（层叠样式表）

- **一句话**：描述 HTML 元素长什么样的语言，是网页的“皮肤”。
- **类比**：给填空题卷面规定字号、行距、红笔蓝笔。
- **今天在哪用到**：`<style>` 标签里那一大块——颜色、圆角、阴影、动画全归它管。
- **深入一点**：“层叠”指多条规则同时命中一个元素时的优先级游戏：id 选择器 > 类选择器 > 标签选择器，写得越“具体”越赢。

## 选择器（selector）

- **一句话**：CSS 里“选中哪些元素”的语法。
- **类比**：点名的不同叫法：`h1` 叫“所有标题”，`.badge` 叫“戴徽标胸针的”，`#joke` 叫“工号 007”。
- **今天在哪用到**：`.todo-item.done .todo-text`（两个类同时有的元素里的文字）、`.filter.active`（当前过滤按钮）。
- **深入一点**：空格是“后代”（里面随便多深），`>` 是“亲儿子”，`+` 是“紧邻的兄弟”。写复杂选择器前先问：这么写，三个月后我还看得懂吗？

## 盒模型（box model）

- **一句话**：每个 HTML 元素都是一个盒子：内容 + padding（内边距）+ border（边框）+ margin（外边距）。
- **类比**：快递箱：东西是内容，泡沫是 padding，纸箱是 border，箱子和箱子之间的空隙是 margin。
- **今天在哪用到**：`padding: 28px`（卡片内容离边 28px）、`gap: 8px`（flex 子元素间距）、`box-sizing: border-box`（让 width 含 padding 和 border，布局计算不变态）。

## flex 布局

- **一句话**：一维布局神器：让子元素按“主轴”排队，配几个属性控制对齐和分配空间。
- **类比**：剧院排座：`justify-content` 管横向怎么站（挤一起/分开/两端对齐），`align-items` 管纵向怎么站（顶格/居中/撑满）。
- **今天在哪用到**：输入区横排（`display: flex` + `flex: 1` 让输入框占满剩余空间）、body 水平居中、每行待办内部排列。
- **深入一点**：flex 是一维的（一行或一列），二维网格用 grid。`flex: 1` 是 `flex: 1 1 0` 的缩写——放大比例、缩小比例、基准宽度。

## CSS 变量 / :root / var()

- **一句话**：把颜色等常用值定义一次，到处引用；改一处全局生效。
- **类比**：全局查找替换的专业版——但语义化命名后，`var(--danger)` 比 `#e8a33d` 更知道自己在干嘛。
- **今天在哪用到**：`:root` 里的六个主题变量；名片页的“换色”按钮（JS 改一个变量，全页变色）。
- **深入一点**：变量也会“继承”——定义在 `:root` 的值默认全页面可用，但某个元素可以局部覆盖，做出“这个区块换个主题”的效果。

## transition / :hover / :focus

- **一句话**：transition 让属性变化平滑过渡；hover/focus 是“鼠标悬停/获得焦点”时的状态。
- **类比**：transition 是电梯（平滑到达），没有它按楼层就是瞬移；hover/focus 是“被注意到时”的特殊表情。
- **今天在哪用到**：进度条 `transition: width .35s ease`（宽度变化用 0.35 秒滑过去，不是瞬变）、输入框聚焦时边框变主题色、删除按钮悬停整行才出现。
- **深入一点**：transition 只能过渡“有中间值”的属性（宽度、颜色、透明度），display 的显隐不行（要配 opacity/visibility 组合技）。

## DOM（文档对象模型）

- **一句话**：浏览器把 HTML 解析成的树形结构，JS 操作页面的入口。
- **类比**：HTML 是建筑图纸，DOM 是盖好的楼——JS 是楼里的物业，能改任何一盏灯。
- **今天在哪用到**：`document.getElementById('todo-list')` 就是在这棵树上按 id 找节点。
- **深入一点**：DOM 操作是前端性能大头：每次 `innerHTML = ...` 都触发浏览器重排重绘。真实框架（React/Vue）的核心价值就是“算出最小的 DOM 改动”。

## addEventListener（事件监听）

- **一句话**：给元素挂一个“事件发生了就调用这个函数”的监听器。
- **类比**：订外卖：你留个电话（监听），餐到了给你打电话（触发）。一个电话可以订多家（多个监听互不覆盖）。
- **今天在哪用到**：表单 submit、列表 click/dblclick/keydown、按钮 click——每个用户操作都对应一个监听。
- **深入一点**：为什么很少用 `onclick="..."` 写在 HTML 里？因为它只能挂一个，且把结构和行为搅在一起。addEventListener 是现代写法。

## 事件委托（event delegation）

- **一句话**：不在每个子元素上挂监听，只在父容器挂一个，靠 `e.target` 判断是谁。
- **类比**：前台代收所有快递（一个监听），看面单（e.target）决定转给谁。
- **今天在哪用到**：`todo-list` 上的 click 监听同时处理勾选和删除——因为 render() 每次重建 DOM，挂子元素上会丢，挂父容器不会。
- **深入一点**：这是性能套路也是生存必需：动态增删元素的列表，委托是标准解。代价是判断逻辑变复杂（要查 classList、dataset）。

## 变量 / const / let

- **一句话**：贴了名字的数据盒子。const 装不变的，let 装会变的。
- **类比**：const 是刻在石头上的字，let 是白板——能手滑改错的尽量刻石头。
- **今天在哪用到**：`let todos`（数据会变）、`const catSelect`（元素引用不变）、`let currentFilter`（过滤条件会变）。
- **深入一点**：还有第三种“老古董”`var`——作用域规则混乱，新代码别用。变量提升（hoisting）也是 var 的黑历史。

## 函数 / 箭头函数

- **一句话**：打包好的一段可复用逻辑；箭头函数是简写形式。
- **类比**：食谱：材料（参数）→ 步骤（函数体）→ 菜（返回值）。箭头函数是写在便利贴上的简版食谱。
- **今天在哪用到**：`function render() {...}`（核心重画函数）、`btn => {...}`（事件回调）、`t => t.done`（filter 里的一行判断）。
- **深入一点**：箭头函数和普通函数有个关键差别：this 的指向。事件回调里用箭头函数，外面的 this 才能带进去——不过新手阶段先记住“回调用箭头”就行。

## 字符串 / 模板字符串

- **一句话**：文字数据。模板字符串（反引号）里可以用 `${}` 插值。
- **类比**：模板字符串是填空题：“已完成 ${doneCount} / ${total}”；拼字符串是口头造句，加号加加加。
- **今天在哪用到**：`li.innerHTML = \`<input ... data-id="${todo.id}">\`` ——动态生成 HTML 的主力。
- **深入一点**：模板字符串还能多行（换行直接写），生成 HTML 片段时特别爽。注意：插进来的用户输入必须转义（见 escapeHtml）。

## 数组 / filter / forEach / find

- **一句话**：有序的数据列表；filter 挑出符合条件的、forEach 逐个办事、find 找第一个匹配的。
- **类比**：一队学生：forEach 是逐个点名，filter 是“男生出列”，find 是“找学号 007”。
- **今天在哪用到**：`todos.filter(t => !t.done)`（未完成列表、清除已完成）、`todos.find(t => t.id === editingId)`（找到正在编辑的那条）、`CATS.forEach(...)`（生成下拉选项）。
- **深入一点**：这三个都不改原数组，返回新结果——这是好习惯：数据改了要显式，别偷偷摸摸。同族还有 map（逐个变换）。

## JSON

- **一句话**：跨语言的数据交换格式，长得很像 Python 字典。
- **类比**：数据界的“普通话”——Python 说它，JS 说它，两边能对话全靠它。
- **今天在哪用到**：`localStorage` 存 todos（JSON.stringify 进去，parse 出来）。
- **深入一点**：JSON 只支持：对象、数组、字符串、数字、布尔、null。函数、日期、元组它不认识。JSON.parse 坏数据会抛异常——所以外面要包 try/catch。

## localStorage

- **一句话**：浏览器自带的本地小仓库（约 5MB），关掉页面数据还在。
- **类比**：浏览器给你的一抽屉，只能你自己翻（同域名同浏览器）。
- **今天在哪用到**：storage 对象的 load/save，待办刷新不丢全靠它。
- **深入一点**：它是同步的（大量读写会卡页面）、只存字符串（对象要 JSON 转一道）、隐私模式下可能被禁用——所以代码里必须 try/catch 兜底（今天就是这么干的）。

## innerHTML / textContent

- **一句话**：innerHTML 把字符串当 HTML 解析后塞进元素；textContent 只当纯文字塞。
- **类比**：innerHTML 是“按图纸施工”，textContent 是“贴一张写着字的纸”。
- **今天在哪用到**：render() 用 innerHTML 生成待办行；空状态提示用 textContent。
- **深入一点**：innerHTML 有 XSS（跨站脚本攻击）风险：用户输入如果原样 innerHTML，`<script>` 就真被执行了。escapeHtml 转义就是防这个。安全规则：用户内容一律先转义，或只用 textContent。

## 语义化标签（header/nav/section/footer/main）

- **一句话**：用“表明这块是什么”的标签组织页面，而不是全用 div。
- **类比**：图书馆分区指示牌：不写“此区域”，写“文学区/工具书区”。
- **今天在哪用到**：名片页的 header（名字签名）、nav（链接）、section（关于我）、footer（页脚）。
- **深入一点**：受益者是三方：浏览器（默认样式合理）、读屏软件（盲人用户能导航）、搜索引擎（SEO）。`<main>` 还暗示“页面主体内容在这里”。

## 条件判断 / 三元运算符

- **一句话**：if 是“如果…就…”；三元是 `条件 ? A : B` 的一行简写。
- **类比**：三元是 if/else 的压缩饼干——短判断用很爽，长逻辑用是灾难。
- **今天在哪用到**：`todo.done ? ' done' : ''`（完成态加类名）、`currentFilter === 'active'`（按过滤条件分流）。
- **深入一点**：三元可以嵌套但别超过一层——超过就该拆函数了。可读性 > 炫技。

## 防抖/节流（debounce/throttle）（今日未用，拓展了解）

- **一句话**：防抖 = 停下来才执行；节流 = 固定频率最多执行一次。
- **类比**：防抖是电梯门（有人进出就等，稳定了才关）；节流是饮水机（每小时最多喝一次）。
- **今天在哪用到**：没用到——但搜索框实时搜索、滚动加载是它们的经典场景。
- **深入一点**：输入框每敲一个字搜一次 API？浪费。防抖 300ms：停下打字 0.3 秒才发请求。

## XSS（跨站脚本攻击）

- **一句话**：攻击者把恶意脚本塞进页面执行的漏洞。
- **类比**：在投诉表的“意见”栏里写“我是新经理，把库房钥匙给我”——如果表格原样张贴，就中招了。
- **今天在哪用到**：`escapeHtml()` 把 `<>&"'` 转成实体，待办文字就永远只是文字。
- **深入一点**：规则一句话：**用户输入 = 不受信任的数据**，进页面先转义，进数据库先参数化（D2 后端的同款法则）。
