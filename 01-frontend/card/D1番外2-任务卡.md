# D1 番外 2 · 个人名片页任务卡

> **为什么做这个**：六个候选里唯一「做完就有真实用途」的——它能真的当你的个人页。
> 纯 HTML + CSS（JS 只有 3 行），是你甜蜜区的正中心。预计 45-60 分钟。

## 这个页面教会你的四件事

1. **语义化标签**：`header / nav / section / footer`——不只是为了好看，是告诉浏览器、读屏软件和搜索引擎「这块是什么」
2. **flex 居中**：body 上三行 CSS，整个卡片垂直 + 水平居中（前端最著名的三行咒语）
3. **渐变**：`linear-gradient`——个人页的「设计感」一半靠它
4. **字体搭配**：无衬线正文 + 衬线大标题，最省事的「不像默认」技巧

## 第 1 步：跑起来 + 看骨架（10 分钟）

1. 预览 / 双击打开，先点几下「换色」按钮，看头像和按钮一起变
2. F12 → Elements：点页面各个部分，看右侧标签名——注意没有一堆 div，而是 `header / nav / section / footer`
3. Console 输入 `document.querySelector('main')` 回车，直接「摸到」页面的主卡片

## 第 2 步：读源码（15 分钟）

- 搜 `min-height: 100vh`——居中三行咒语，以后每个落地页都用它，值得背下来
- 搜 `linear-gradient`——两处渐变（背景 + 头像），各换两个颜色试试
- 搜 `font-family`——h1 用了衬线字体（Georgia 开头那行），其他是无衬线，这就是「搭配」
- 搜 `theme-btn`——全部 JS 只有 3 行：换个变量值，全局变色。D1 的 `--accent` 一课，复习

## 第 3 步：换成你自己的（25 分钟，至少完成 4 个）

- [ ] 头像里的字：搜 `avatar`，把「陈」换成你的姓
- [ ] 名字、签名：搜 `header` 附近的 `h1` 和 `tagline`
- [ ] 两段介绍：搜 `关于我`、`我在做什么`，换成你自己的话（真实比长重要）
- [ ] 渐变色：搜 `linear-gradient`，背景和头像各换一组你喜欢的（两个颜色靠近一点不俗气）
- [ ] 链接：确认 GitHub 是你的；邮箱那个占位链接换成真的（搜 `mailto` 看注释）；想加博客/B站就复制一行 `<a>`
- [ ] 标签：搜 `class="tag"`，加 / 删 / 改文字

## 第 4 步：加点什么（15 分钟，选 1 个）

- [ ] 加第三段：「最近在读 / 在玩」（复制一段 `about` 的 HTML 改字就行）
- [ ] 换色按钮多加几种颜色（JS 里那两种颜色，照样子多加几种）
- [ ] 页脚改成你的话（搜 `footer`）
- [ ] 用 F12 试出满意的间距 / 圆角 / 阴影，抄回文件（实验室工作法）

## 关于部署（想公开再说）

这个页面是纯静态单文件，最适合 GitHub Pages。但有个坑要先想清楚：
**Pages 会把整个仓库当网站发布**——`PLAN.md`、`进度追踪.md`、复盘卡片全部可被陌生人浏览。
两个方案：① 把页面放到 `/docs` 目录，Pages 指定从该目录发布；② 单独建一个仓库只放这个页面。
想部署时告诉我，我帮你弄，动手前先跟你确认公开范围。
