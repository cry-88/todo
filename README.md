# 每日体验一个计算机方向

> 用 14 天低成本采样，拿一份「个人方向匹配画像」——不求学会，只求手感。

## 项目介绍

个人学习实验项目：每天体验一个计算机细分方向，用**排除法**（不求学会、只求手感）找到个人适配路线。每个方向配一个低门槛、可运行的 demo，每天一个 git commit，14 天后基于复盘数据做方向决策，避免凭感觉选赛道。

**体验路线**：D0 通用基础 → D1–D5 Web 光谱（前端/后端/Agent/网络/数据库）→ D6–D7 好奇心组（安全/游戏）→ D8–D10 数据家族（数据科学/ML/CV）→ D11–D12 底层（系统/嵌入式）→ D13 部署运维 → D14 算法体验 + 总结决策。

**当前进度：D1 前端开发已完成**（2026-10-28），完整计划见 [PLAN.md](PLAN.md)，逐日数据见 [进度追踪.md](进度追踪.md)。

## 技术栈

- **纯 HTML + CSS + JavaScript**：单文件、零依赖、零构建，浏览器直接打开即用
- **Git**：每天一个 commit，14 天形成可见的成长轨迹
- 后续方向按需引入 Python / Node / Docker 等（见 PLAN.md 环境基线）

## 启动方式

无需安装任何依赖：

```bash
git clone https://github.com/cry-88/todo.git
cd todo
```

然后用浏览器打开 `01-frontend/index.html`（双击，或拖入浏览器窗口）。

**Todo 应用功能**：添加待办 / 勾选完成 / **双击文字就地编辑**（回车保存、ESC 取消、失焦自动保存）/ 删除 / 全部·未完成·已完成过滤 / 清除已完成 / localStorage 刷新不丢失。

## 部署说明

纯静态站点，可部署到任意静态托管：

| 平台 | 操作 |
|------|------|
| GitHub Pages | Settings → Pages → Source 选 `main` 分支根目录，访问 `https://cry-88.github.io/todo/01-frontend/` |
| Vercel / Netlify | 关联仓库或拖入文件夹，零配置一键部署 |
| 本地预览 | `python -m http.server 8000` 后访问 `http://localhost:8000/01-frontend/` |

## 工程决策记录（D1）

- **单文件架构**：CSS/JS 内联进 `index.html`，保证任何环境（本地/预览/转发）零依赖可用；工程化多文件结构留待后续方向引入
- **数据驱动渲染**：所有交互最终只改 `todos` 数组，界面交给 `render()` 重画——前端核心心智模型
- **编辑态模式**：`editingId` 状态驱动 render 分支（展示态/编辑态），回车/失焦保存、ESC 经 `cancelEdit` 标志位走取消流程，规避「移除聚焦元素触发 blur」的浏览器行为差异
- **CSS 变量即语义契约**：`--muted`=弱化文字、`--danger`=警示色，改动前先搜 `var(--x)` 确认影响面
- **存储容错**：localStorage 用 try/catch 封装，禁用环境下降级为内存版，页面不白屏

## 方法论（为什么这么做）

时间盒 60–90 分钟；卡壳超 20 分钟跳过并记录；区分「任务挫败」（环境/语法）与「方向信号」（概念无聊）；记录沉浸时刻而非只打兴趣分。
