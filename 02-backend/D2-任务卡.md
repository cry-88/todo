## 第 1 步：跑起来（15 分钟）

1. VS Code 打开 `02-backend` 文件夹，在终端执行（PowerShell 和 Git Bash 都能用）：
   ```
   cd 02-backend
   venv/Scripts/python app.py
   ```
2. 看到 `Running on http://127.0.0.1:5000` 就是成功了。**先别关这个终端——后端的"显微镜"就是它。**
3. 浏览器打开 <http://localhost:5000/api/joke/random> ，刷新几次，每次换一条笑话
4. 每刷新一次，回头看终端——是不是多了一行日志？**这就是今天最核心的画面：请求流过服务器。**  
   顺便认识这行日志的结构：`"GET /api/joke/random HTTP/1.1" 200` = 用什么方法、要什么网址、结果如何
5. 打开 <http://localhost:5000/play> ——点"再来一个"按钮，同时盯终端：每点一次跳一行日志  
   （这个页面就是 D1 你写过的那种 HTML/JS，它只负责把服务器运回来的数据显示出来）
6. **故障排查（重要技能）**：
   - 终端报 `Address already in use` → 5000 端口被占。搜 `port=` 改成 5050 再来一遍（端口冲突是后端日常）
   - 页面按钮没反应 → F12 → Console 看红色报错（D1 的技能，今天复用）
   - 想看请求运回的原始数据 → F12 → Network 面板 → 点请求 → Response

## 第 2 步：读源码，建立根概念（20 分钟）

- **请求 → 处理 → 响应**：整个后端就这一条线。浏览器要一个网址（请求），`@app.route(...)` 路由表决定交给哪个函数（处理），函数返回 JSON（响应）。**路由表就是你定义的规则**
- **JSON**：前后端之间运数据的标准格式，长得像 Python 字典（键值对）。`jsonify()` 负责把字典变成 JSON
- **状态码**：`200` 找到了，`404` 没有。搜 `404` 看代码里怎么"如实说没有"
- 读 `random_joke` 和 `one_joke` 两个函数，注意 `/api/joke/<int:joke_id>` 里尖括号的用法——网址的一部分变成了函数参数
- 亲手验证 404：浏览器访问 <http://localhost:5000/api/joke/999>
- 注意文件最后的 `if __name__ == "__main__":`——作用是"直接运行才启动服务器，被 import 时不启动"（第 4 步写测试要靠它）
